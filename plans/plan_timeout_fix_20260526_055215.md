# Plan: Enforce timeout_sec in AgnoRunner

## Problem
`AgnoRunner.timeout_sec` is stored but never enforced. The `agent.run()` and `agent.arun()` calls block indefinitely, causing runaway configs like `03_gemini_like` to run for 5+ hours.

## File to modify
`src/features/agent_integration/agno_runner.py`

## Changes required

### 1. Async path — `_run_with_mcp()` method (around line 312)

Wrap `agent.arun()` with `asyncio.wait_for()`:

**Before:**
```python
with self._rate_limiter:
    response: RunOutput = await agent.arun(task_description)
```

**After:**
```python
with self._rate_limiter:
    response: RunOutput = await asyncio.wait_for(
        agent.arun(task_description),
        timeout=float(self.timeout_sec),
    )
```

Also update the outer `except Exception` block to handle `asyncio.TimeoutError`:
- `asyncio.TimeoutError` is a subclass of `Exception` so it will be caught automatically, but add an explicit log message so it's visible:
  - Inside the `except Exception:` block, check `isinstance(exc, asyncio.TimeoutError)` and log a warning like `"Agent timed out after %ss"`.

Actually simpler: add a dedicated `except asyncio.TimeoutError` **before** the generic `except Exception:`:
```python
except asyncio.TimeoutError:
    _log.warning("Agent async run timed out after %ss", self.timeout_sec)
    success = False
except Exception:
    _log.exception("Agno MCP agent execution failed")
    success = False
```

### 2. Sync path — `run()` method (around line 402)

Use `concurrent.futures.ThreadPoolExecutor` to enforce timeout on the blocking `agent.run()` call.

`concurrent.futures` is already used inline in the same method. Add a top-level import at the top of the file:
```python
import concurrent.futures
```

**Before:**
```python
with self._rate_limiter:
    response: RunOutput = agent.run(task_description)
```

**After:**
```python
with self._rate_limiter:
    with concurrent.futures.ThreadPoolExecutor(max_workers=1) as _pool:
        _future = _pool.submit(agent.run, task_description)
        response: RunOutput = _future.result(timeout=self.timeout_sec)
```

The `concurrent.futures.TimeoutError` will propagate to the outer `except Exception:` block (which sets `success = False`). Add an explicit check or dedicated except:
```python
except concurrent.futures.TimeoutError:
    _log.warning("Agent sync run timed out after %ss", self.timeout_sec)
    success = False
except Exception:
    _log.exception("Agno agent execution failed")
    success = False
```
