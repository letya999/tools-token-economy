# Plan: LLM Judge — Post-Benchmark Evaluation

**Goal:** Add a two-score LLM-based evaluator that runs at the end of each benchmark config run and scores:
1. `task_solved_score` (0.0–1.0): did the agent actually solve the task?
2. `tool_correctness_score` (0.0–1.0): were the config-prescribed tools used correctly?

All data needed already exists per run: `agent_messages.json`, `final.patch`, `metrics.json`, task description, `AgentConfig.tools`.

---

## Files to Create

### `src/features/llm_judge.py`

New module. Contains two classes:
- `JudgeReport(BaseModel)` — structured output from the judge
- `LLMJudge` — makes two separate OpenAI API calls and returns a `JudgeReport`

**`JudgeReport` fields:**
```python
class JudgeReport(BaseModel):
    task_solved_score: float          # 0.0–1.0
    task_solved_reasoning: str
    tool_correctness_score: float     # 0.0–1.0
    tool_correctness_reasoning: str
    judge_model: str
```

**`LLMJudge.__init__`:**
- `judge_model: str | None = None` — defaults to `os.getenv("JUDGE_MODEL", "gpt-4.1-mini")`
- Creates an `openai.OpenAI()` client (same client the project already uses via AgnoRunner)
- If `OPENAI_API_KEY` is not set, `evaluate()` must return a zeroed `JudgeReport` with `judge_model="skipped"` and log a warning — never raise

**`LLMJudge.evaluate(...)` signature:**
```python
def evaluate(
    self,
    task_description: str,
    agent_messages: list[dict],
    patch: str | None,
    config_tools: list[str],
    tests_passed: int,
    tests_total: int,
    success: bool,
) -> JudgeReport:
```

**Call 1 — Task Solved:**

System prompt:
```
You are an objective evaluator for a software engineering benchmark.
You will be shown: a task description, the git diff of changes made by an AI agent, and test results.
Return ONLY a JSON object with two fields: "score" (float 0.0 to 1.0) and "reasoning" (1-2 sentences).
Score 1.0 = task fully solved. Score 0.0 = task not attempted or completely wrong.
Be strict: partial solutions that miss key requirements score 0.3–0.6.
```

User message:
```
TASK:
{task_description}

TEST RESULTS: {tests_passed}/{tests_total} passed. Overall success: {success}

GIT DIFF (changes made by agent):
{patch or "(no changes made)"}
```

Parse response as JSON `{"score": float, "reasoning": str}`.

**Call 2 — Tool Correctness:**

Extract tool_calls from `agent_messages`: for each message where `role == "assistant"` and `tool_calls` is non-empty, collect `{"tool": call.function.name, "args_summary": str(call.function.arguments)[:200]}`.

System prompt:
```
You are an objective evaluator for a software engineering benchmark.
You will be shown: the list of tools the agent was supposed to use, and the actual sequence of tool calls the agent made.
Return ONLY a JSON object with two fields: "score" (float 0.0 to 1.0) and "reasoning" (1-2 sentences).
Score 1.0 = all prescribed tools were used meaningfully and in a sensible workflow.
Score 0.5 = some tools used but others ignored or misused.
Score 0.0 = prescribed tools entirely ignored.
Ignore "write" and "patch" tools — they are always expected and not diagnostic.
```

User message:
```
PRESCRIBED TOOLS FOR THIS CONFIG: {config_tools}

ACTUAL TOOL CALLS MADE (in order):
{json.dumps(tool_call_sequence, indent=2)[:3000]}
```

Parse response as JSON `{"score": float, "reasoning": str}`.

**Error handling:** wrap both calls in try/except. On any exception (timeout, parse error, API error), log a warning and return zeroed scores with reasoning="judge call failed: {error}".

**Temperature:** 0.0 for both calls (deterministic judge).

### `src/orchestrator/benchmark.py`

In `run_suite()`, after `run_metrics = runner.run(...)` returns and BEFORE creating `final_result`:

1. Import `LLMJudge` at the top of the file
2. Read `agent_messages.json` from `log_path` (already known in scope, file was written by `runner.run()`)
3. Read `final.patch` from `os.path.join(run_dir, "final.patch")` if it exists
4. Instantiate `LLMJudge()` and call `.evaluate(...)` passing:
   - `task_description=full_task`
   - `agent_messages=messages_data` (parsed JSON list, empty list if file missing)
   - `patch=patch_content` (str or None)
   - `config_tools=config.tools`
   - `tests_passed=run_metrics.tests_passed`
   - `tests_total=run_metrics.tests_passed + run_metrics.errors`  — NOTE: use `eval_outcome` fields if accessible; otherwise derive from metrics
   - `success=run_metrics.success`
5. Merge judge scores onto `run_metrics` using `run_metrics.model_copy(update={...})`
6. Do the same in `run_failed_configs()` (same pattern, same location)

**Important:** wrap the entire judge block in try/except so a judge failure never aborts the benchmark run.
